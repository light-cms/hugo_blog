# About

This is a basic displayable Hugo starter. It includes:

- Home page (`layouts/home.html` + `content/_index.md`)
- Posts section (`content/posts/`)
- Base, list, and single layouts in `layouts/`
- Plain CSS in `static/css/style.css` — no theme dependency

Run `hugo server` to preview, `hugo` to build to `public/`.
